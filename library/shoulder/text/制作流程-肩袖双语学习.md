# 肩袖双语学习材料：制作与维护流程

更新：2026-10-09。当前输出包含 5 个章节（第 06 章论文阅读已移到每日推送）、19 张可编辑 SVG（2026-10-09 新增图 18、19；PDF 仍是 17 张图的 2026-10-06 版）、英文完整叙述与中文对应翻译，以及经过模型清单核对的 3D 跳转。

## 1. 内容顺序与表达规则

| 章节 | 学习任务 | 当前实现 |
| --- | --- | --- |
| 01 Anatomy | 辨认结构和起止点 | 四块肩袖肌分别标 O（Origin，起点）与 I（Insertion，止点），附完整走行句；其后是大圆肌、斜方肌两张卡片（2026-10-09，见第 7 节） |
| 02 Innervation | 把神经路线放回人体解剖 | 肩胛上神经、腋神经实体解剖示意；流程图作补充；区分 C/T、椎骨与脊神经 |
| 03 Movement | 连接附着、作用线与运动 | 起止点对照、力偶、肩肱节律与阶段性完整说明 |
| 04 Clinical anatomy | 将检查与局部解剖对照 | 英中术语、检查表、重排后的临床图和穴位叠加图 |
| 05 Review | 简记与完整专业表达并行 | 保留三句原口诀，提供英文完整叙述、中文翻译和四组完整问答 |

原来的第 06 章 Paper reading 已于 2026-10-09 移出本章，改为每日推送内容（CH-01、N-5）：论文记录和原文在 `daily/papers/hando-2026-dry-needling.json`，核对记录、来源范围和只在论文里用到的读音在 `daily/papers/hando-2026-dry-needling/`。

- 图示和专业名称均先英文、后中文。连续描述使用完整英文句子，再给对应中文，避免把中文句子的几个名词换成英文就当作英语表达。
- 肌肉描述采用：**The [muscle] originates from [origin], passes [direction or relation], and inserts onto [insertion].** 然后说明神经支配、动作与稳定作用。
- `Origin → Insertion` 是附着顺序。图中的虚线 O→I 与实线受力箭头分开，不能把两者当成同一方向。
- 起止点为示意区域；未绘出的骨面不能随意加点。上斜方肌的锁骨止点等未显示部分，在图内独立文字区说明。
- `C = Cervical（颈部）`，`T = Thoracic（胸部）`。`C5 vertebra` 指第5颈椎；神经支配的 `C5–C6` 指贡献纤维的颈神经节段。图中分别标注骨与神经。
- 制作说明、AI 提示词和方法记录放在本文件；学习正文保留知识、图示、英语表达、练习和来源。

## 5. 构建与检查

在“肩袖”目录运行：

```sh
python3 library/shoulder/text/build-reading.py
```

生成器会检查：六个章节、所有图示占位符、SVG XML有效性、网页ID唯一性、Markdown图片路径、3D term是否存在于词库或骨标清单。它同时更新独立HTML、Markdown、public与dist阅读页。

若修改了3D应用代码，还需运行：

```sh
cd library/shoulder/3d
pnpm build
```

最后进行浏览器检查：

1. 在实际阅读宽度检查四张起止点图、两张神经实体图、臂丛图、临床图与穴位图。
2. 展开流程图和肌肉时间轴，检查文字不超出SVG边界、不与其他标注重叠；宽图使用横向滚动，不强行压缩字体。
3. 检查每组完整英文之后都有对应中文；四组问答展开后都包含完整答案。
4. 点击代表性肌肉与新增骨标链接，等待模型加载，核对实际选中名称；其余链接用词库与模型对象清单核验。
5. 保留截图和构建记录，确认 `public/reading.html` 与 `dist/reading.html` 内容一致。

本轮已完成：构建及 TypeScript 检查；17张图的显示文字边界/相互重叠检查；Supraspinatus与Lesser tubercle的实际跳转；已支持肌肉的左右侧模型对象核对。论文全文未取得等证据缺项随论文记录移到 `daily/papers/`。
