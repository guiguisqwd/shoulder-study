# 第 1 层 · 生理解剖方向规范

继承 [00-general.md](../00-general.md)。主题特有的数值（配色、3D ID、论文数字）不写在这里，放第 2 层主题数据；下面出现的肩袖值只作示例。

## 写法（AN-01 至 AN-09）

| 编号 | 规则 |
| --- | --- |
| AN-01 | 解剖专业词汇、骨性结构、神经、动作、图标和答案按 G-01 英文在前，例：`Supraspinatus 冈上肌`。网页里用 `bilingual-pair`（英文 `<p lang="en">` 后接 `<p class="translation" lang="zh-Hans">`）。 |
| AN-02 | 每块肌肉记录 Origin、Insertion、Course、Action、Innervation，五项都有中英和来源。 |
| AN-03 | 肌肉句式固定：**The [muscle] originates from [origin], passes [direction or relation], and inserts onto [insertion]. It is innervated by [nerve and spinal segments] and contributes to [action].** 之后再写稳定作用等。句式是模板，内容按该主题资料核验，不套用其他关节的数据。 |
| AN-04 | 区分 `C = Cervical 颈部`、`T = Thoracic 胸部`、`L = Lumbar 腰部`、`S = Sacral 骶部`。`C5 vertebra` 指第 5 颈椎；神经支配里的 `C5–C6` 指贡献纤维的脊神经节段。正文和图都要分开骨与神经。 |
| AN-05 | 动作从起止点和拉力线讲起，必要时讲力偶、节律和发力顺序；动作部分关联参与肌肉的具体走行。 |
| AN-06 | 复习保留口诀原文，但每条都配完整专业英文、中文翻译和完整问答。 |
| AN-07 | **读音（必做，2026-10-08 确认）。** 每个英文关键术语有 IPA、大写重音音节（如 `su-pra-spi-NA-tus`）和词典链接；有朗读按钮时一并提供。穴位名带声调拼音，并用中文朗读。 |

## 图示（AN-10 至 AN-19）

| 编号 | 规则 |
| --- | --- |
| AN-10 | 每张图是独立可编辑 SVG，文件名 `NN-中文名.svg`；图内标题先英文后中文；图内所有 `id` 加图号前缀，避免 filter、marker 冲突。 |
| AN-11 | 风格：米白纸底，手绘感线条；一个主题内肌肉配色全套一致（配色表放主题数据）；神经用金色，穴位用红点。 |
| AN-12 | 神经必须画在人体解剖结构上；深层神经要让表层肌肉半透明；流程图只能作补充。每日短版的神经图从脊髓画起。 |
| AN-13 | `Origin → Insertion` 用虚线 O→I 表示附着顺序；受力和动作用实线箭头；两者不能混成一个方向。 |
| AN-14 | 起止点只画示意区域；图里没画出的骨面不随意加点；未显示部分（如上斜方肌的锁骨止点）写在图内单独文字区。 |
| AN-15 | 每张图底部写 `Schematic; pathway and layers are simplified. 解剖示意；走行与层次经过简化。` |
| AN-16 | 可读性：文字不出 SVG 边界、不互相重叠、不压在所指结构上；引线互不交叉且指向正确。宽图在网页里用 `.figure-scroll` 横向滚动（min-width 950 或 1150 px），不靠缩小字号塞下；必要时用两行标签、引线或分图。 |
| AN-17 | 每张图与正文一致：图中标注的结构、O/I、穴位都在正文出现，正文提到的图都存在。 |

## 穴位（AN-20 至 AN-29）

| 编号 | 规则 |
| --- | --- |
| AN-20 | 每个穴位写：国标定位（GB/T 12346-2021；可附 WHO 2008 英文定位）、从皮肤到深层的层次、相关肌肉或触发点、怎么找、安全提示（肺尖、胸膜、腋动脉、臂丛、四边孔等）。 |
| AN-21 | 穴位画在周围解剖结构上（叠加图），红点标注。 |
| AN-22 | 层次图和 3D 穴位都写明：学习参照，没有临床校准，**不表示进针深度、方向或路径**。 |
| AN-23 | 涉及干针、针刺、触发点时，列出相关穴位和对应的干针目标。 |
| AN-24 | 只写原文里有的穴位内容；原文没写针刺部位时，不用二手评论替代，也不推断“试验扎了哪些穴”。 |

## 论文阅读（AN-30 至 AN-39）

2026-10-09 起论文阅读不在章节里，是每日学习的「新」内容 N-5（[../daily/README.md](../daily/README.md)）；写法规则不变。

方法沿用 scientific-critical-thinking SKILL.md v1.5（K-Dense-AI）。

| 编号 | 规则 |
| --- | --- |
| AN-30 | 顺序：研究问题和设计 → 人群 → 干预与比较的组 → 主要 vs 次要结局 → 效应量和 95% CI → 偏倚 → 适用范围 → 结论边界。 |
| AN-31 | 数字照原文抄，含单位和时间点。例：1 年 SPADI 组间差值 −7.51（95% CI −16.57 到 1.54）；PASS 写明是绝对百分点。 |
| AN-32 | OR 的参照组未说明就保持未明，不换算成风险比。 |
| AN-33 | 写明核对到哪一层：摘要、全文、研究方案、注册信息。研究方案只代表计划的方法；计划招募数与报告人数之差不当作失访人数。 |
| AN-34 | 区分原文结论和自己的解读；不用未核验的二手评论概括试验操作细节。 |
| AN-35 | 正式标题、作者、期刊、DOI、来源文件名原样保留。 |

## 3D 链接（AN-40 至 AN-49）

| 编号 | 规则 |
| --- | --- |
| AN-40 | 链接用 `?term=<id>`（新主题加 `?topic=<id>`）、穴位用 `?point=<code>`；ID 必须在模型词库或 landmarks 文件里真实存在，不按英文名猜。已有的肩袖链接要继续可用。 |
| AN-41 | 模型里没有的结构，映射写 `null`，正文注明“模型缺项”；不链接到别的肌肉冒充。没有模型的部位全部写 `null`。 |
| AN-42 | 骨骼、骨性标志、肌肉分别核对；选中大骨骼不代表每个标志都能单独定位。 |
| AN-43 | 扩展 3D 模型属于共享能力改动，先问用户。算扩展的：新增骨骼、肌肉、部位、网格或模型文件，或者让已有链接（`?term=`、`?point=`、`?topic=`）打开的结果变了。不算扩展的：只改 3D 程序里读网址、跳转、界面这类逻辑，模型和已有链接的结果都不变；这类改动可以直接做，但要写进制作记录，并跑 `pnpm build`（几何或标记有变时加 `pnpm test:geometry`）。 |
| AN-44 | **章节附加模型。** 自带模型缺的肌肉或其他网格，不另找模型、不改自带 GLB：在 `library/<id>/3d/atlas-addon.json` 列清单，用共用脚本 `site/build/atlas/` 从固定版本的 Z-Anatomy 源文件导出本章附加模型（做法见 [site/build/atlas/README.md](../../site/build/atlas/README.md)）。结构按实测位置对应，不按源网格名：清单的 `checks` 为每块附加结构写位置检查，全部通过（QC-09）才能用。源网格名与解剖不符时，导出前用 `renameSourceObjects` 改名，让 ID 按国际解剖学名词（Terminologia Anatomica），并在 `mappingNotes` 写明；例：Z-Anatomy 把斜方肌降部（上部）和升部（下部）的名字弄反，肩部清单已改正。新增网格仍先问用户（AN-43）。 |
