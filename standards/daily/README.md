# 每日学习规程 · Daily learning

继承 [00-general.md](../00-general.md) 和 [library/rules.md](../library/rules.md)。

用户 2026-10-08 定的分工：**知识库**（`library/`）是生成好的大内容，按部位分章；**每日学习**（`daily/`）按本规程从知识库取材，生成当天该学的东西。

用户 2026-10-09 定的学法：**周日学一章，周一到周六补全这一章。** 每日推送要分清两件事：推什么（**内容**，如穴位、肌肉、解剖结构）和怎么推（**形式**，如自测、flashcard）。学什么、哪天学（学习计划）属于内容制作；几点生成、几点发送、怎么存档属于推送流程。

## 一周的节奏（DL-10 至 DL-15）

| 编号 | 规则 |
| --- | --- |
| DL-10 | 每周日学本周的**章节**：知识库的一章，按 CH-01 五部分（解剖、神经、动作、临床解剖、复习）。这是一周的总量。 |
| DL-11 | 周一至周六，每日包对本周章节做**补全**。每天 = 1–2 项「新」+ 1–2 项「旧的夯实」+ 当天到期的间隔复习。内容类型见下面的 N、O 清单，形式见 F 清单。 |
| DL-12 | 学习计划写在 `daily/plan/weeks.json`：每周写明周日日期、章节 id，以及周一到周六每天的内容（N-x / O-x 和具体条目）与形式（F-x）。改计划只改这个文件。 |
| DL-13 | 「新」内容按本周章节的部位选，不跨到别的章节。穴位选本章部位的穴位，写明所属经脉。 |
| DL-14 | 周六做本周小测（新旧混合），并做跨周间隔复习。 |
| DL-15 | 间隔复习按 1/3/7/14/30 天排，跨周进行；复习条目来自前几周的「新」和「旧的夯实」。 |

## 取材规程（DL-01 至 DL-07）

| 编号 | 规则 |
| --- | --- |
| DL-01 | 【目标，等生成流程改造】「旧的夯实」里的肌肉、骨、神经、动作事实直接取自本周章节 `library/<id>/`，不在每日包里另写一份。 |
| DL-02 | 本周章节在周日之前必须已经发布（`topic.json` 的 `status` 为 `published`）。还没有时，先按 [library/steps.md](../library/steps.md) 把章节做完。 |
| DL-03 | 【目标，等生成流程改造】每日包的图优先复用知识库章节的 SVG；需要新画的图，同时加回该章节的 `figures/`。 |
| DL-04 | 每日包注明本周章节 id，读者能从当天内容回到完整章节。 |
| DL-05 | 质量要求与知识库相同（G-01 至 G-09、AN 系列规则）；每条内容类型另有下表列出的必须项。 |
| DL-06 | 每日包的源文件在 `daily/days/<date>/`，网页在 `site/public/daily/<date>/`；发送、存档和定时由推送流程负责，不在本规范内。 |
| DL-07 | 论文记录（N-5）放 `daily/papers/<id>.json`，写明属于哪一章；某天读这篇论文时从这里取。 |

## 内容：推什么

### 新（章节里没有，或只点到）

| 编号 | 内容 | 必须写到 |
| --- | --- | --- |
| N-1 | 穴位 | 所属经脉和编号（如 LI4 手阳明大肠经）；其余按 AN-20 至 AN-24 |
| N-2 | 康复流程 | 某个问题从**检测到治疗**的完整路径：主诉与问诊 → 观察、触诊 → ROM、MMT、特殊检查 → 鉴别诊断与转诊信号 → 治疗（手法、运动处方、针刺或干针、宣教）→ 进阶与回归标准；每一步有来源（G-02） |
| N-3 | 损伤与病理 | 常见损伤、机制、分级、自然病程 |
| N-4 | 临床案例 | 一个具体病人，按 SOAP 写，串起本周章节和康复流程；注明是教学案例，不是真实病人 |
| N-5 | 论文 | AN-30 至 AN-35 |
| N-6 | 触诊与体表定位 | 在身上摸到哪块骨、哪块肌、哪个点，怎么确认摸对了 |
| N-7 | 检查操作 | 特殊检查的具体做法、阳性表现、敏感度和特异度（写明来源） |

### 旧的夯实（章节里有，反复练）

| 编号 | 内容 |
| --- | --- |
| O-1 | 肌肉：起点、止点、神经（带节段）、动作、走行句（AN-03） |
| O-2 | 骨性结构与骨性标志 |
| O-3 | 关节：类型、关节囊、韧带、运动轴和平面、松弛位和紧张位 |
| O-4 | 神经分布：节段、走行、皮节和肌节、卡压点 |
| O-5 | 血管供应 |
| O-6 | 动作与生物力学：拉力线、力偶、节律、发力顺序 |
| O-7 | 临床解剖：结构对应的特殊检查、神经损伤后的表现 |
| O-8 | 英文术语：读音、拼写（AN-07） |

## 形式：怎么推

| 编号 | 形式 | 主要配给 |
| --- | --- | --- |
| F-1 | 精讲（图解 + 正文） | 新 |
| F-2 | 流程图（检测 → 治疗） | N-2 |
| F-3 | 实际案例（SOAP） | N-4 |
| F-4 | 口语实操：英文问诊、给病人解释、向同事汇报；附示范对话和读音 | N-2、N-4 |
| F-5 | 论文精读 | N-5 |
| F-6 | 自测题（选择、填空、看图标注） | 旧 |
| F-7 | Flashcard | 旧 |
| F-8 | 听音辨词：听英文读音，写出结构名 | O-8 及所有旧 |
| F-9 | 拼写默写 | O-8 |
| F-10 | 间隔复习（DL-15） | 旧 |
| F-11 | 手敲笔记：给提示，凭记忆打出来，再对照原文 | 旧 |
| F-12 | 口述或画出走行：凭记忆讲一条神经或一块肌肉 | O-1、O-4 |

新内容类型或新形式取下一个空编号，写进上面的表，并在 [CHANGELOG](../CHANGELOG.md) 记一笔。

**现状（2026-10-09）**：按周计划从 2026-10-11（肩袖周）开始。每日生成流程（`daily/pipeline.py`）从这天起读 `weeks.json`，按「内容 × 形式」检查和生成（格式见 `daily/CONTENT_SCHEMA.md` 的 v2 部分）；周日章节日自动生成。定时生成任务仍暂停，它的提示要改成按本规程走，由用户决定何时恢复。DL-01、DL-03 仍是目标：旧的夯实目前由生成时照章节写，还没有直接引用章节数据。
